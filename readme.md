## Структура проекта

Проект представляет собой статический сайт, который открывается в браузере без сборки (чистый HTML, CSS, JS).

```text
tz-22-kompyuternyy-klub-respawn/
├── index.html          # Главная страница
├── zones.html          # Игровые зоны и описание железа
├── prices.html         # Цены, калькулятор и пакеты
├── games.html          # Список установленных игр с поиском
├── tournament.html     # Турнир «Зимний кубок» и регистрация
├── reaction.html       # Тест на реакцию и промокод
├── contacts.html       # Форма бронирования и контакты
├── thanks.html         # Подтверждение брони
├── privacy.html        # Политика конфиденциальности
├── 404.html            # Страница ошибки
├── css/
│   └── style.css       # Единый файл стилей
├── js/
│   ├── main.js         # Бургер-меню и общие скрипты
│   ├── calculator.js   # Логика калькулятора стоимости
│   ├── games.js        # Живой поиск по играм
│   ├── reaction-game.js# Игра на реакцию
│   ├── thanks.js       # Генерация номера брони
│   └── tournament.js   # Модальное окно регистрации
├── img/                # Изображения (формат JPEG/WebP)
├── files/              # Файлы для скачивания
├── docs/               # Документация (PDF, CSV, скрипты)
│   ├── prompts.md      # Журнал запросов к нейросети
│   ├── events.md       # Таблица событий GA4
│   ├── utm.csv         # Реестр UTM-ссылок
│   ├── rules.pdf       # Правила клуба
│   └── tournament-rules.pdf # Регламент турнира
└── screens/            # Скриншоты для отчета (GA4, DataLens и т.д.)
