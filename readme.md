## Структура проекта

Проект представляет собой статический сайт, который открывается в браузере без сборки (чистый HTML, CSS, JS).

```
tz-22-kompyuternyy-klub-respawn/
├── index.html          # Главная страница
├── zones.html          # Игровые зоны и описание железа
├── prices.html         # Цены, калькулятор и пакеты
├── games.html          # Список установленных игр с поиском
├── tournament.html     # Турнир «Зимний кубок» и регистрация
├── reaction.html       # Тест на реакцию и промокод
├── contacts.html       # Форма бронирования и контакты
├── thanks.html         # Подтверждение брони
├── privacy.html        # Политика конфиденциальности
├── 404.html            # Страница ошибки
├── css/
│   └── style.css       # Единый файл стилей
├── js/
│   ├── main.js         # Бургер-меню и общие скрипты
│   ├── calculator.js   # Логика калькулятора стоимости
│   ├── games.js        # Живой поиск по играм
│   ├── reaction-game.js# Игра на реакцию
│   ├── thanks.js       # Генерация номера брони
│   └── tournament.js   # Модальное окно регистрации
├── img/                # Изображения (формат JPEG/WebP)
├── files/              # Файлы для скачивания
├── docs/               # Документация (PDF, CSV, скрипты)
│   ├── prompts.md      # Журнал запросов к нейросети
│   ├── events.md       # Таблица событий GA4
│   ├── utm.csv         # Реестр UTM-ссылок
│   ├── rules.pdf       # Правила клуба
│   └── tournament-rules.pdf # Регламент турнира
└── screens/            # Скриншоты для отчета (GA4, DataLens и т.д.)
```

## Технологии и особенности реализации

* **Frontend:** HTML5, CSS3 (Flexbox, Grid, CSS Variables), Vanilla JavaScript (ES6).
* **Шрифты:** Orbitron (заголовки) и Inter (основной текст) через Google Fonts.
* **Цветовая палитра:** Согласно брендбуку (`#0F0E17` — фон, `#7B2FF2` — фиолетовый, `#29D3F5` — неоновый голубой).
* **Адаптивность:** Сайт корректно отображается на устройствах шириной 375px (смартфоны), 768px (планшеты) и 1280px+ (десктопы). Кнопки адаптированы под нажатие пальцем (min 44x44 px).
* **Аналитика:** Внедрен Google Analytics 4 (gtag.js) с настроенными событиями (`cta_click`, `generate_lead`, `booking_calc` и др.). Все вызовы `gtag()` находятся в едином файле.
* **Формы:** Две формы (бронь и регистрация) отправляют данные в Google Apps Script, который записывает их в Google Таблицу.

## Как запустить проект локально

Так как проект не использует сборщики, для запуска достаточно открыть файл `index.html` в любом современном браузере.

Для корректной работы модулей и скриптов (чтобы не было ошибок CORS) рекомендуется запустить локальный сервер. Для этого можно установить расширение Live Server через VS Code.
